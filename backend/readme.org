* General flow with associated workflow states
#+begin_src

  -------------------------------------------------------
  workflow_state: discovery/none
  =======================================================

  Client: emit session.start

  |
  v

  Server:
  if session_id not provided
  -> new session, new run
  -> emit discovery.question

  if valid/existing session_id provided -> 
  -> new run
  -> use checkpoint to set workflow state and emit next action

  if invalid/nonexistent session_id provided ->
  -> session doesnotexist/expired ack/error?
  -> dont do anything else
  -------------------------------------------------------


  -------------------------------------------------------
  workflow_state: discovery
  =======================================================

  Server: emit discovery.question

  |
  v

  Client: emit discovery.answer

  |
  v

  Server:
  if question_id is not current or answer invalid in some way:
  -> send rejection ack

  if valid msg:
  -> agent do its work
  -> save as checkpoint
  -> get next question
  -> emit discovery.question
  -------------------------------------------------------

  -------------------------------------------------------
  workflow_state: profile_review
  =======================================================

  after required questions have been answered

  Server: emit profile.ready

  |
  v

  Server: emit profile.snapshot

  |                          
  v                          

  Client: emit profile.confirm    (or)   Client: emit profile.request_changes

                                         |
                                         v
                                         
                                         Server: emit discovery.question
  -------------------------------------------------------

  -------------------------------------------------------
  workflow_state: planning
  =======================================================
  Client: emit profile.confirm

  |
  v

  Server:
  save profile
  do llm stuff for planning and optimization
  somewhere in between send status updates?
  if client decision required:
  -> emit plan.snapshot with draft plan
  -> emit decision.request
  -------------------------------------------------------

  -------------------------------------------------------
  workflow_state: decision_required
  =======================================================
  Server: emit decision.request

  |
  v

  Client: emit decision.response

  |
  v

  Server:
  if another decision required:
  -> emit plan.snapshot with draft plan
  -> emit decision.request

  if all decisions made:
  -> save final trip plan
  -> emit plan.snapshot with final plan
  -> emit profile.ready
  -------------------------------------------------------

  -------------------------------------------------------
  workflow_state: cancelled
  =======================================================
  Client: emit run.cancel

  |
  v

  Server:
  cancel the current run
  -------------------------------------------------------

  -------------------------------------------------------
  workflow_state: expired
  =======================================================
  Client: emit session.close / session.start with invalid session_id

  |
  v

  Server:
  end the current session
  -------------------------------------------------------
                                           

#+end_src
