# Decision records

Add one dated Markdown record per material orchestration or product-architecture decision. Record context, decision, alternatives, consequences, owner, approval status, and the source contract or requirement affected.

Decision records must distinguish:

- **Committed decisions:** required by `README.md`, `TEAM.md`, or the canonical `docs/` contracts.
- **Working assumptions:** useful for implementation but not yet approved product requirements.
- **Open decisions:** unresolved choices that must not be silently encoded as architecture or scope.

Do not use this directory for speculative ideas. When a decision changes a contract, update the relevant source-of-truth document and record the relationship here.
